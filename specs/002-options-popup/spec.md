# Feature Specification: オプション画面のポップアップ表示 (options-popup)

**Feature Branch**: `002-options-popup`

**Created**: 2026-11-10

**Status**: Draft

**Input**: User description: "オプション画面をpopupで表示できるようにしたいです。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - ツールバーアイコンクリックによるオプションポップアップの表示 (Priority: P1)

ユーザーはブラウザのツールバーにあるMdPicker拡張機能アイコンをクリックすることで、現在のWebページから離れることなく、その場でポップアップとして設定画面を表示・確認できる。

**Why this priority**: 拡張機能の設定変更を行う際、わざわざ右クリックして「オプション」を選んだり、拡張機能管理ページを開いたりする手間をなくし、最も手軽にアクセスできるようにするための基盤機能であるため。

**Independent Test**: ブラウザツールバーのアイコンをクリックし、現在の画面の右上に設定ポップアップが表示されることを確認する。

**Acceptance Scenarios**:

1. **Given** 拡張機能がブラウザにインストールされツールバーに表示されている状態、**When** ユーザーが拡張機能アイコンを左クリックしたとき、**Then** オプション画面がドロップダウン形式のポップアップとして即座に開く。
2. **Given** オプションポップアップが開いている状態、**When** ユーザーがポップアップ外の画面をクリックしたとき、**Then** ポップアップが自動的に閉じる。

---

### User Story 2 - ポップアップ内での設定確認および変更の即時反映 (Priority: P1)

ユーザーはポップアップ内でファビコン設定やテンプレートの追加・削除・ピン留め・デフォルト指定などの設定を行い、その変更が即座に保存・適用される。

**Why this priority**: ポップアップ上で閲覧だけでなく既存のオプション画面と同等の設定変更が行えなければ、ユーザーの利便性向上の目的が達成できないため。

**Independent Test**: ポップアップ内で設定（ファビコンのサイズ変更やテンプレートの追加など）を変更し、ポップアップを閉じて再度開いた際、あるいはコンテキストメニューを開いた際に、設定内容が正しく反映されていることを確認する。

**Acceptance Scenarios**:

1. **Given** ポップアップが開いている状態、**When** ユーザーが設定項目（ファビコン設定やテンプレート一覧）を変更したとき、**Then** 変更内容が即座に保存され、完了メッセージが表示される。
2. **Given** ポップアップでテンプレートを新しく追加またはピン留め設定を変更したとき、**When** Webページ上で右クリックコンテキストメニューを開いたとき、**Then** 変更後のテンプレート一覧・順序が即座に反映されている。

---

### User Story 3 - ポップアップから広い画面（別タブ）でのオプション画面起動 (Priority: P2)

画面解像度が低い環境や、テンプレートの入力欄・一覧を広々と操作したいユーザーのために、ポップアップ上から新しいブラウザタブでフルサイズのオプション画面を開く手段を提供する。

**Why this priority**: ブラウザのポップアップ領域にはサイズ上限（最大800px × 600px）があるため、長いフォーマットテンプレートの編集や複雑な設定を行う際の操作性を担保するセーフティネットとして価値があるため。

**Independent Test**: ポップアップ内にある「全画面で開く（新しいタブで開く）」リンク/ボタンをクリックし、新しいタブでオプション画面が開くことを確認する。

**Acceptance Scenarios**:

1. **Given** ポップアップが開いている状態、**When** ユーザーが「別タブで開く」アイコンまたはリンクをクリックしたとき、**Then** ポップアップが閉じ（またはそのまま）、ブラウザの新しいタブとしてオプション画面が開く。

---

### Edge Cases

- **ブラウザウィンドウが極端に小さい場合**: ポップアップの内容が画面外にはみ出さず、スクロールバーによって全設定項目（テンプレート一覧や追加フォーム）へアクセスできること。
- **設定保存中にポップアップが閉じられた場合**: 非同期の保存処理が中断されず、データの不整合や破損が発生しないこと。
- **高解像度（Retina）ディスプレイおよびズーム環境**: ポップアップ内のテキストやフォーム要素が適切にスケーリングされ、レイアウト崩れが発生しないこと。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、ブラウザツールバーの拡張機能アイコンをクリックした際に、オプション設定を表示するポップアップを展開しなければならない (MUST)。
- **FR-002**: ポップアップ内のオプション画面は、既存のオプション画面で提供されている全設定項目（ファビコン挿入の有無、ファビコンサイズ、デフォルトテンプレート選択、テンプレート一覧のピン留め・削除、テンプレート追加、初期値リセット）を操作可能でなければならない (MUST)。
- **FR-003**: ポップアップ内のUIは、ブラウザのポップアップ領域サイズ（最大幅800px、最大高さ600px）に適したレイアウトで表示され、はみ出る場合は垂直スクロールによってすべての項目へアクセス可能でなければならない (MUST)。
- **FR-004**: ポップアップ内で変更されたすべての設定は即座にストレージへ保存され、開いているWebページのコンテキストメニューや動作へ遅滞なく同期されなければならない (MUST)。
- **FR-005**: ポップアップ画面のヘッダーまたはフッター領域に、新しいブラウザタブで全画面のオプション画面を開くための遷移リンクまたはボタンを提供しなければならない (MUST)。
- **FR-006**: システムは、従来の拡張機能管理画面（`chrome://extensions/`）や右クリックメニューの「オプション」からの設定画面起動機能も引き続き維持しなければならない (MUST)。

- **FR-007**: ポップアップ画面は、ファビコン設定・全テンプレート一覧・追加フォームなどの全設定項目を幅約500px前後のポップアップに適したレイアウトで表示し、ヘッダー領域に「新しいタブで開く」ボタンを配置しなければならない (MUST)。
- **FR-008**: ツールバーの拡張機能アイコンの左クリック操作は常にオプションポップアップの表示を起動し、コンテキストメニューやキーボードショートカット（Command+Shift+M / Ctrl+Shift+M）によるMarkdownコピー機能と競合せず共存しなければならない (MUST)。

### Key Entities *(include if feature involves data)*

- **Extension Action (ツールバーアクション)**: ブラウザツールバー上に常駐する拡張機能アイコン。クリックイベントによってポップアップを開くエントリポイント。
- **Options View (オプション表示画面)**: ユーザーが設定を変更するためのUI。ポップアップ内表示モードとフルタブ表示モードの2つのコンテキストを持つ。
- **User Settings (ユーザー設定データ)**: ファビコン表示設定、ファビコンサイズ、登録済みテンプレート一覧、ピン留め状態、ショートカット既定テンプレートIDなど、ストレージに永続化される設定エンティティ。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ユーザーはツールバーアイコンのワンクリック（所要時間1秒未満）でオプション画面へアクセスできる。
- **SC-002**: ポップアップ内で行った設定変更（ファビコンやテンプレートの編集）が、ポップアップを閉じることなくリアルタイム（500ミリ秒以内）に反映される。
- **SC-003**: 画面サイズが幅450px〜600px、高さ400px〜600pxのポップアップ表示領域において、横スクロールを発生させることなく全設定機能が利用できる。
- **SC-004**: 既存のコンテキストメニュー経由やショートカットキーによるMarkdownコピー機能の動作に一切の影響（性能低下や設定同期の不整合）を与えない。

## Assumptions

- **ブラウザ環境**: Google Chromeの最新バージョン（Manifest V3対応環境）を対象とする。
- **表示領域の制約**: Chromeのポップアップ仕様に基づき、最大幅800px、最大高さ600pxの枠組み内で完結するようにスクロールやレイアウトを構成する。
- **設定データの共通性**: ポップアップ表示用の独立した設定項目は新設せず、既存のオプション設定と完全に同一のデータ構造（`chrome.storage.sync`）を共有する。
