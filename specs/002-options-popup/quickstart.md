# クイックスタート検証ガイド (Phase 1: Quickstart Guide)

## 概要
本ガイドは、オプション画面のポップアップ表示機能（`002-options-popup`）が意図通りに動作していることをエンドツーエンドで検証するための実行手順書です。

---

## 1. 事前準備 (Prerequisites)

1. **プロジェクトのビルド**:
   ```bash
   npm run build
   ```
   ビルド成果物が `./package/js/` に出力されていることを確認します。

2. **Chromeへの拡張機能読み込み**:
   - Google Chromeを開き、URLバーに `chrome://extensions/` を入力します。
   - 右上の「デベロッパーモード」を有効にします。
   - 「パッケージ化されていない拡張機能を読み込む」をクリックし、本プロジェクトの `package/` ディレクトリを選択します。
   - ブラウザのツールバーに MdPicker アイコンが表示されている（またはピン留め可能になっている）ことを確認します。

---

## 2. 検証シナリオ (Validation Scenarios)

### シナリオ 1: ツールバーアイコンからのポップアップ起動と表示確認
- **操作**:
  1. 任意のWebページを開いた状態で、ツールバーの MdPicker アイコンを左クリックします。
- **期待結果**:
  - アイコンの直下にオプション画面がポップアップとして即座に開くこと。
  - ファビコン設定、テンプレート一覧テーブル、テンプレート追加フォームが表示され、横スクロールなしで綺麗に収まっていること。
  - ヘッダーに「MdPicker」タイトルおよび「別タブで開く」ボタンが表示されていること。

### シナリオ 2: ポップアップ内での設定変更と即時同期の確認
- **操作**:
  1. ポップアップ内で「Include favicon in page link」のチェックボックスをオン（またはオフ）に切り替えます。
  2. 新規テンプレート（例: 名前 `Slack`, 形式 `<{{url}}|{{title}}>`）を入力して「Add」をクリックします。
- **期待結果**:
  - 「Saved」の緑色ステータスが一瞬表示されること。
  - テンプレート一覧に新テンプレートが即座に追加されること。
  - 任意のWebページで右クリックコンテキストメニューを開いた際、追加したテンプレートがメニューに反映されていること。

### シナリオ 3: 「別タブで開く」操作の確認
- **操作**:
  1. ツールバーアイコンをクリックしてポップアップを開きます。
  2. ヘッダー右上にある「別タブで開く」ボタンをクリックします。
- **期待結果**:
  - ポップアップが閉じ、新しいブラウザタブとして全画面のオプション画面（`options.html`）が開くこと。
  - 設定内容（シナリオ2で追加したテンプレートなど）が完全な状態で表示されていること。

### シナリオ 4: 既存アクセス経路の互換性確認
- **操作**:
  1. `chrome://extensions/` のMdPicker詳細画面で「拡張機能のオプション」をクリックします。
  2. ツールバーのアイコンを右クリックして「オプション」をクリックします。
- **期待結果**:
  - 従来通りオプション画面が正常に起動すること。

---

## 3. 合否判定基準
上記すべてのシナリオでエラーや表示崩れ、設定の消失が発生しないことをもって機能検証合格とします。
