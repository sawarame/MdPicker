# クイックスタート・動作検証ガイド (Quickstart & Validation Guide)

**機能ブランチ**: `001-pin-template-menus`  
**対象仕様書**: [spec.md](./spec.md)  
**作成日**: 2026-11-08  

---

## 1. 事前準備 (Prerequisites)

1. **プロジェクトのビルド**:
   ```bash
   npm run build
   ```
2. **Chrome拡張機能の読み込み / 再読み込み**:
   - Google Chrome で `chrome://extensions` を開く。
   - 「デベロッパーモード」を有効化する。
   - 「パッケージ化されていない拡張機能を読み込む」から、本リポジトリの `package/` ディレクトリを選択（または再読み込みアイコンをクリック）。

---

## 2. エンドツーエンド検証シナリオ (Validation Scenarios)

### シナリオ 1: デフォルト状態での動作確認（後方互換性テスト）

1. **初期状態の確認**:
   - 拡張機能を読み込んだ直後、または拡張機能のオプション画面で「Reset to Defaults」を実行する。
2. **リンク右クリックメニューの確認**:
   - 任意のWebページ（例: `https://example.com`）上のリンクを右クリックする。
3. **期待される結果**:
   - 第1階層（トップレベル）に「Markdown形式でリンクをコピー」が表示されている。
   - 「その他の形式でコピー」（または「リンクを別形式でコピー」）サブメニューが存在し、開くと Slack、Scrapbox、HTML、Markdown (日付付き) が並んでいる。

---

### シナリオ 2: 設定画面でのピン留め変更と即時反映テスト

1. **オプション画面の操作**:
   - 拡張機能アイコンを右クリックし「オプション」を開く。
   - テンプレート一覧テーブルの「Slack」行の「トップレベルに表示」チェックボックスにチェックを入れる。
   - 「HTML」行のチェックボックスにもチェックを入れる。
2. **リンク右クリックメニューの確認**:
   - 開いているWebページのリンクを右クリックする。
3. **期待される結果**:
   - 第1階層に以下の順序で直接メニューが表示される：
     1. 「Markdown形式でリンクをコピー」
     2. 「Slack形式でリンクをコピー」
     3. 「HTML形式でリンクをコピー」
   - 「その他の形式でコピー」サブメニューを開くと、チェックを入れていない「Scrapbox」および「Markdown (日付付き)」のみが格納されている。
   - 「Slack形式でリンクをコピー」をクリックすると、クリップボードに `<URL|タイトル>` 形式でコピーされる。

---

### シナリオ 3: すべてのテンプレートをピン留めした場合（サブメニュー非表示テスト）

1. **オプション画面の操作**:
   - テンプレート一覧のすべての行の「トップレベルに表示」にチェックを入れる。
2. **リンク右クリックメニューの確認**:
   - Webページのリンクを右クリックする。
3. **期待される結果**:
   - 全テンプレート形式が第1階層に並び、「その他の形式でコピー」親メニュー自体が表示されない。

---

### シナリオ 4: すべてのピン留めを解除した場合（サブメニューのみ格納テスト）

1. **オプション画面の操作**:
   - テンプレート一覧のすべてのチェックボックスを外す。
2. **リンク右クリックメニューの確認**:
   - Webページのリンクを右クリックする。
3. **期待される結果**:
   - 第1階層に個別のテンプレート形式は表示されず、「その他の形式でコピー」サブメニューのみが表示される。
   - そのサブメニューを開くと、登録されているすべてのテンプレート形式が表示される。

---

### シナリオ 5: ページ余白右クリックでの連動確認テスト

1. **操作**:
   - シナリオ2の状態（Markdown, Slack, HTMLがピン留め）で、Webページの何もない余白部分を右クリックする。
2. **期待される結果**:
   - 第1階層に「Markdown形式でページをコピー」「Slack形式でページをコピー」「HTML形式でページをコピー」が並ぶ。
   - クリックすると、現在のタブのタイトルとURLが該当形式でコピーされる。
